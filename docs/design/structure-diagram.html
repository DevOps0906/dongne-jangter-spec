중고거래마켓 화면 구조도

platform-docs 디자인 가이드의 구조 패턴(A~O)과 시각 아키타입(V-A~V-N)을 21개 화면에 지정한 결과입니다. 화면을 누르면 오른쪽에 상세가 열리고, 범례의 패턴을 누르면 그 패턴을 쓰는 화면만 강조됩니다.

화면 트리

표기: 패턴 칩(구조) + 회색 테두리 칩(시각). G페이지는 상세를 전체 페이지로 여는 변형입니다.

앱 진입 (탭 밖, 최초 1회)
앱 셸

핵심 거래 흐름

동네 인증부터 매너 평가까지 사용자가 한 번의 거래에서 지나는 화면 순서입니다. 각 단계를 누르면 위 트리에서 해당 화면이 선택됩니다.

패턴 사용 현황

한 화면이 패턴 두 개를 쓰면(예: B + G) 양쪽에 모두 셉니다.

화면 수 (패턴별)

  • D칸반 · 판매중 → 예약중 → 판매완료는 상태 배지 + 선택 시트로 바꾼다
  • E J K L O캘린더, 에디터+미리보기, 노드 캔버스, 분석 탐색, 스프레드시트 · 해당 화면이 없다

공용 위젯 구현 순서

원본 공용화 기준: 쓰지 않는 패턴은 미리 만들지 않는다. 여러 화면이 공유하는 뼈대부터 만든다.

    시각 규칙과 수정 제안

    모든 화면 공통

    • 트레이딩 문법 적합도 부적합: 캔들·호가창·네온 다크를 쓰지 않는다
    • 포인트컬러는 화면당 1개. 브랜드 오렌지는 CTA·선택 상태·현재 탭에만
    • 상태 5종 필수: 기본 · 로딩(스켈레톤) · 빈 상태 · 오류 · 권한 없음
    • 상태는 색만으로 표시하지 않는다. 판매중·예약중·판매완료는 텍스트 배지
    • 가격·매너온도·조회수는 등폭 숫자(tabularFigures)
    • 위젯 안에서 Color(0xFF…) 직접 사용 금지, AppTokens만 참조
    • 검증: 라이트/다크, 360dp 폭, 글자 크기 130%, TalkBack
