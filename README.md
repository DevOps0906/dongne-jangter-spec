# 동네장터 (Dongne Jangter)

동네 기반 중고거래 앱의 기획·디자인 패키지입니다. Flutter 구현 전 단계의 산출물을 모아 두었습니다.

- 패키지 목표: 동네 인증 → 상품 등록·검색 → 실시간 채팅 → 거래 후기(매너온도), 그리고 동네생활 커뮤니티

## 구성

| 경로 | 내용 |
|---|---|
| `docs/planning/master-plan.md` · `.pdf` | 종합 기획안 (13개 섹션, 기술 스택, 데이터 모델, 재사용 전략) |
| `docs/design/pattern-mapping.md` | 플랫폼 디자인 패턴(A~O)과 비주얼 아키타입(V-코드)을 21개 화면에 매핑한 표 |
| `docs/design/structure-diagram.html` | 21개 화면 구조도. 브라우저에서 열면 패턴별 필터와 상세 패널을 쓸 수 있습니다 |
| `design/canvas/` | 디자인 캔버스. `canvas.json`과 보드 22개(기준 보드 `Main`, 탭바 `TabBar`, 화면 20개) |

## 화면 구조 (5개 탭, 21개 화면)

- 홈: 홈 피드 · 검색 · 상품 상세 · 가격 제안
- 동네생활: 피드 · 게시글 상세 · 글쓰기
- 글쓰기: 사진 올리기 · 상품 정보 입력
- 채팅: 채팅 목록 · 채팅방
- 나의 동네장터: 메인 · 판매·구매 내역 · 관심목록 · 판매자 프로필 · 매너 평가 · 설정
- 진입: 로그인 · 동네 인증 · 동네 범위 지도

## 디자인 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| brand | `#C2410C` | CTA, 현재 탭, 미읽음 표시 (화면당 강조색 1개) |
| ink | `#18202C` | 본문, 제목 |
| muted | `#5A6472` | 보조 텍스트 |
| line / ground | `#E3E6EA` / `#F4F5F7` | 구분선, 배경 |
| danger | `#B91C1C` | 파괴적 동작, 탈퇴 영역 |

상태색(예약중 파랑, 판매완료 회색)과 매너온도색(파랑·청록·보라·장미 4구간)은 브랜드색과 분리했습니다.

## 알려진 사항

- 라이트 테마만 있습니다. 다크 테마는 아직 없습니다.
- 디자인 캔버스의 `.dc.html` 파일은 `./support.js`를 참조합니다. 이 파일은 Artifact 런타임이 제공하므로 레포에 포함하지 않았습니다.
- 기획안과 패턴 매핑 문서에는 참고한 레퍼런스 앱 기준 표기(`com.nomad.karrot`, 중고거래마켓)가 남아 있습니다. 패키지 ID와 명칭은 아직 `동네장터`로 바꾸지 않았습니다.
- 상품 사진과 지도는 `[상품 사진]`, `[지도 · 네이버 지도 SDK]` 자리 표시입니다.
